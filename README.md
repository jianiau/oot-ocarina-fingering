# 🎵 時之笛按法轉換器 (Ocarina of Time Fingering Converter)

輸入**簡譜**或**音名**,輸出《薩爾達傳說 時之笛》的**按鍵順序**,並可用琴鍵、笛鍵試聽與播放整段。
單一 HTML 檔、無外部相依,直接用瀏覽器開啟即可。

## 功能

- 輸入格式:簡譜(可選調)、音名(如 `F#4`、`Bb3`)
- 輸出按法:基本音 + 升降修飾(R / Z / 左搖桿)
- 按法版本:Switch 2 重製版(預設配置 / 經典配置)、Switch 1 NSO、N64 原版、自訂
- 一鍵平移:譜超出可按範圍時,整首平移到合適位置(可限定只平移八度)
- 琴鍵(C4–C6)、時之笛 5 鍵可點擊發聲,可播放整段並高亮目前的音
- 內建 11 首時之笛歌曲範例

## 使用方式

**本機**:下載 `index.html`,雙擊開啟。

**GitHub Pages**:Settings → Pages → Source 選 `main` / root,幾分鐘後即可在
`https://<帳號>.github.io/<repo 名>/` 使用。

### 輸入語法

| 格式 | 範例 | 說明 |
|---|---|---|
| 簡譜 | `1 2 3 4 5 6 7 1'` | `'` 高八度、`,` 低八度、`#4` `b7` 升降、`0` 休止 |
| 音名 | `D4 F#4 Bb3` | 省略八度視為 4;`0` 或 `r` 為休止 |
| 時值 | `1:2`、`D4:2` | 後綴 `:n` 表示 n 拍;單獨的 `-` 延長前一音 1 拍 |

## 按法原理

時之笛只有 5 個基本音,再用修飾鍵偏移音高:

| 基本音 | MIDI |
|---|---|
| D4 / F4 / A4 / B4 / D5 | 62 / 65 / 69 / 71 / 74 |

| 修飾 | 偏移 |
|---|---|
| R | +1 半音 |
| Z(Switch 為 ZL) | −1 半音 |
| 左搖桿上 / 下 | +2 / −2 半音(全音) |
| R + 搖桿上 / Z + 搖桿下 | +3 / −3 |

所以可按音域為 **B3(59)–F5(77)**,共 19 個半音。

對任一音,程式在 5 個基本音中找出偏移量在 ±3 以內的組合,取「難度」(`COST`)最低者:
不修飾 0 < R/Z 1 < 搖桿 1.5 < 兩者疊加 2.5。搖桿微調是連續的、較難抓準,因此優先用 R/Z。

**一鍵平移**:試 −24 ~ +24 半音的所有平移,依序比較 ①可按音數最多 ②總難度最低 ③平移幅度最小。

## 程式結構(`index.html`)

全部在一個檔案內,`<script>` 以註解分成幾區:

| 區塊 | 內容 |
|---|---|
| 設定區 | `OC`、`PRE`、`COST` 等常數 |
| 樂譜解析 | `parse()`:簡譜 / 音名 → `{m: MIDI, b: 拍數}` |
| 按鍵名稱 | `labels()`、`modl()`:各版本配置的顯示文字 |
| 按法計算 | `fing()`:MIDI → 基本音 + 修飾;`approx()`:找最近可按音 |
| 顯示 | `render()`:畫出按法卡片與文字輸出 |
| 音效 | `tone()`:Web Audio(sine + triangle + 顫音) |
| 琴鍵 / 笛鍵 | 動態產生鍵盤與 5 鍵,點擊時發聲並可寫入輸入框 |

## 想修改?看這裡

| 想做的事 | 改哪裡 |
|---|---|
| 新增 / 修改範例歌曲 | `PRE` 物件,格式為 `'歌名':'音名序列'` |
| 新增按法版本(例如其他手把配置) | ① HTML 的 `<select id="ver">` 加 `<option>`;② `labels()` 加 5 個基本音的按鍵名稱;③ `modl()` 加 R / Z / 搖桿上 / 搖桿下 的名稱 |
| 修正某配置的按鍵 | `labels()` 與 `modl()` 中對應版本那一行 |
| 調整按法偏好(例如改優先用搖桿) | `COST` 表 |
| 改變音域上限(±3 半音) | `fing()` 內的 `Math.abs(o)>3` 與 `COST` |
| 改音色 | `tone()`(波形、顫音頻率 `lf.frequency`、包絡 `linearRampToValueAtTime`) |
| 改鍵盤範圍 | 「琴鍵」區的 `for(let m=60;m<=84;m++)`(MIDI 60 = C4) |
| 改配色 / 深色模式 | `<style>` 開頭的 CSS 變數(`:root`) |
| 平移搜尋範圍 | `$('auto').onclick` 內的 `-24 ~ 24` |

## 已知限制

- 修飾鍵(R / Z / 搖桿)的偏移值依社群與維基資料整理,實機上的音準請自行確認。
- Switch 2 配置的按鍵名稱依實際重製版配置整理;若版本更新有異,請在 `labels()` / `modl()` 修改,或使用「自訂」。
- 音效為簡易合成音,不代表遊戲內實際音色。
